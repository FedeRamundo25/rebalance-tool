01 / STATE MANAGEMENT & PERSISTENCE

Reactive Store & LocalStorage Synchronization

State operations leverage an event-driven pub/sub pattern (`store.js`) ensuring seamless cross-component synchronization. Any team rotation or vacancy update automatically updates memory state and triggers immediate disk persistence. 

// Pub/Sub listener dispatch on mutation
subscribe(listener) {
  this.listeners.push(listener);
  return () => { this.listeners = this.listeners.filter(l => l !== listener); };
}
notify() {
  localStorage.setItem('rebalance_state', JSON.stringify(this.state));
  this.listeners.forEach(fn => fn(this.state));
}
02 / DOMAIN LOGIC

Capacity & Vacancy Calculation Engine

The capacity engine calculates headcount deltas per role (Backend, Frontend, QA, Data) across multi-quarter milestones. It detects under-allocated domains and flags pending vacancies in real time.
