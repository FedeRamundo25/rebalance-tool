# 🚀 Engineering Rebalance & Capacity Planning Tool (v3.5)

Herramienta web interactiva basada en un tablero Kanban multi-hito para que Engineering Managers e integrantes de Leadership planifiquen capacidad, simulen rotaciones entre squads, realicen seguimiento de vacantes y auditen cambios en tiempo real.

---

## 🛠️ Arquitectura y Tecnologías
- **Frontend:** Vanilla JS / HTML5 / Tailwind CSS via CDN
- **Persistencia:** LocalStorage & Portabilidad JSON (Exportación/Importación completa)
- **CI/CD:** GitHub Actions (Pruebas unitarias y Despliegue automático a GitHub Pages)
- **Testing:** Vitest
